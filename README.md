## 📌 Description
Folder Encrypter & Vault Archiver secures sensitive directories into encrypted file vaults with authenticated password protection.

---

## ✨ Features
- Folder encryption using AES-256-GCM authenticated encryption standard
- Zero-knowledge architecture ensuring data privacy and key isolation
- Instant folder locking/unlocking with virtual vault mounting support
- Tamper detection and anti-forensic security wiping options
- Backup vault creation with recovery seed file generation

---

## 🛠️ Tech Stack & Architecture
- **Language / Framework**: Python 3.10+ / Qt (PySide6 / PyQt)
- **Core Modules**: Modular engine architecture, async event dispatching, decoupled utility functions
- **Target OS**: Windows, macOS, Linux

## 🚀 Quick Start & Installation

### Prerequisites
- **Python**: Version 3.10 or higher installed
- **Git**: Installed for cloning repositories

### Setup Instructions
```bash
# 1. Clone the repository
git clone https://github.com/hsinidev/012-Folder-Encrypter-Vault-Archiver.git

# 2. Navigate to project directory
cd 012-Folder-Encrypter-Vault-Archiver

# 3. Install required dependencies
pip install -r requirements.txt

# 4. Launch the Application
python app.py
```
*(Note: If `app.py` is absent, launch with `python main.py`)*
